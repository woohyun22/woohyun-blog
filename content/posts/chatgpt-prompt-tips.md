## 같은 ChatGPT인데 왜 답변이 다를까?

ChatGPT를 사용할 때 **어떻게 질문하느냐**에 따라 답변의 질이 크게 달라집니다. 잘 작성된 프롬프트 하나가 10번의 대화보다 낫습니다.

## 핵심 원칙 5가지

### 1. 역할을 부여하세요

**나쁜 예시:**
> 마케팅 문구 써줘

**좋은 예시:**
> 너는 10년 경력의 마케팅 카피라이터야. 20대 여성을 타겟으로 한 화장품 광고 문구를 5개 작성해줘.

### 2. 구체적으로 요청하세요

**나쁜 예시:**
> 블로그 글 써줘

**좋은 예시:**
> "직장인 시간 관리 방법"이라는 주제로 블로그 글을 작성해줘.
> - 분량: 2000자 내외
> - 형식: 서론-본론(5가지 방법)-결론
> - 톤: 친근하고 쉬운 말투
> - 각 방법마다 구체적인 예시 포함

### 3. 예시를 제공하세요

**좋은 예시:**
> 아래 형식으로 제품 설명을 작성해줘:
>
> [제품명]: 무선 이어폰 A
> [핵심 특징]: 노이즈 캔슬링, 30시간 배터리
> [타겟]: 출퇴근 직장인
>
> 예시:
> "출퇴근길의 소음, 이제 잊으세요. A 이어폰의 노이즈 캔슬링이 당신만의 공간을 만들어드립니다."

### 4. 출력 형식을 지정하세요

```
다음 정보를 표 형식으로 정리해줘:
| 항목 | 장점 | 단점 | 가격 |
```

```
JSON 형식으로 출력해줘:
{
  "제목": "",
  "요약": "",
  "키워드": []
}
```

### 5. 단계별로 사고하게 하세요

> 이 문제를 단계별로 풀어줘:
> 1. 먼저 문제를 분석해
> 2. 가능한 해결책을 3개 제시해
> 3. 각 해결책의 장단점을 비교해
> 4. 최선의 방법을 추천해

## 실전 프롬프트 템플릿

### 블로그 글 작성
```
역할: 너는 SEO 전문 블로거야.
주제: [주제]
키워드: [키워드1], [키워드2], [키워드3]
요구사항:
- 2000자 이상
- H2, H3 태그 활용
- 키워드를 자연스럽게 3회 이상 포함
- 실용적인 팁 중심
- 마무리에 CTA 포함
```

### 이메일 작성
```
다음 상황에 맞는 비즈니스 이메일을 작성해줘:
- 상황: [상황 설명]
- 받는 사람: [관계]
- 톤: [격식/친근]
- 핵심 메시지: [전달할 내용]
- 길이: [짧게/보통/길게]
```

### 코드 작성
```
다음 요구사항에 맞는 [언어] 코드를 작성해줘:
- 기능: [설명]
- 입력: [입력 형식]
- 출력: [출력 형식]
- 에러 처리 포함
- 주석 포함
```

### 번역
```
다음 텍스트를 [언어]로 번역해줘:
- 톤: [격식/일상/비즈니스]
- 의역보다 직역 선호 / 직역보다 의역 선호
- 전문 용어는 영어 병기

[번역할 텍스트]
```

## 고급 기법

### Chain of Thought (사고의 사슬)
> "단계별로 생각하면서 답변해줘"를 추가하면 복잡한 문제에서 정확도가 올라갑니다.

### Few-shot 학습
원하는 스타일의 예시를 2~3개 보여주면 그 스타일을 따라합니다.

### 제약 조건 추가
> "~하지 마", "~은 제외해" 등의 부정형 지시도 효과적입니다.

## 자주 하는 실수

1. **너무 짧은 프롬프트**: "글 써줘" → 원하는 결과를 얻기 어렵습니다
2. **모호한 표현**: "좋은 글" → "전문적이고 신뢰감 있는 톤"으로 구체화
3. **한 번에 너무 많은 요청**: 복잡한 작업은 단계별로 나누세요
4. **피드백 없이 재시도**: 마음에 안 들면 구체적으로 수정 요청하세요

## 마무리

프롬프트 작성은 **연습**이 필요합니다. 위 템플릿을 기반으로 자신만의 프롬프트를 만들어보세요. 핵심은 **역할 + 구체적 요청 + 형식 지정**입니다.
