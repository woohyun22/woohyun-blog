## 블로그 글을 써도 검색에 안 나온다면?

열심히 블로그 글을 써도 구글 검색에 내 글이 나타나지 않는다면, **구글 서치 콘솔(Google Search Console)** 등록을 안 했기 때문일 수 있습니다.

구글 서치 콘솔은 구글에게 "내 블로그가 여기 있으니 검색에 포함해줘"라고 알려주는 도구입니다. 무료이며, 블로그 운영자라면 반드시 설정해야 합니다.

## 구글 서치 콘솔이란?

구글 서치 콘솔은 구글이 제공하는 무료 웹마스터 도구로, 다음 기능을 제공합니다.

- **검색 노출 현황**: 내 블로그가 어떤 키워드로 검색되는지 확인
- **색인 요청**: 새 글을 구글에 바로 알려 빠르게 검색에 반영
- **사이트맵 제출**: 블로그 전체 구조를 구글에 알려줌
- **오류 확인**: 크롤링 오류, 모바일 사용성 문제 등 확인

## Step 1. 구글 서치 콘솔 접속

1. [search.google.com/search-console](https://search.google.com/search-console)에 접속
2. 구글 계정으로 로그인
3. "속성 추가" 클릭

## Step 2. 속성 유형 선택

두 가지 방식이 있습니다.

### URL 접두어 (추천)
- 블로그 주소를 입력 (예: `https://yourblog.com`)
- 다양한 인증 방법 지원
- 초보자에게 추천

### 도메인
- 도메인 전체를 등록 (DNS 인증 필요)
- 서브도메인까지 모두 포함
- 커스텀 도메인이 있을 때 사용

**추천**: 처음이라면 "URL 접두어" 방식을 선택하세요.

## Step 3. 소유권 인증

가장 쉬운 방법은 **HTML 메타 태그** 인증입니다.

1. 구글이 제공하는 메타 태그 코드를 복사
2. 블로그의 `<head>` 태그 안에 붙여넣기
3. "확인" 버튼 클릭

```html
<meta name="google-site-verification" content="인증코드" />
```

### Hugo 블로그의 경우
- `layouts/partials/extend_head.html` 파일에 메타 태그 추가
- 또는 `hugo.toml`의 `[params]` 섹션에 설정

## Step 4. 사이트맵 제출

사이트맵은 블로그의 모든 글 목록을 구글에 알려주는 파일입니다.

1. 서치 콘솔 좌측 메뉴에서 "사이트맵" 클릭
2. 사이트맵 URL 입력: `sitemap.xml`
3. "제출" 클릭

Hugo는 자동으로 `sitemap.xml`을 생성해줍니다. 별도 설정 없이 바로 제출하면 됩니다.

## Step 5. 색인 요청하기

새 글을 작성하면 구글에 바로 알릴 수 있습니다.

1. 서치 콘솔 상단 검색창에 새 글 URL 입력
2. "색인 생성 요청" 클릭
3. 보통 1~3일 내에 구글 검색에 반영

**팁**: 매번 수동으로 하기 귀찮다면, 사이트맵을 제출해두면 구글이 자동으로 새 글을 발견합니다.

## 서치 콘솔 활용 팁

### 1. 검색 실적 분석
- 어떤 키워드로 유입되는지 확인
- 클릭률(CTR)이 낮은 글의 제목/설명 개선
- 노출은 많지만 클릭이 적은 키워드에 집중

### 2. 커버리지 확인
- "유효" 페이지 수가 실제 글 수와 일치하는지 확인
- "제외됨" 페이지가 있다면 원인 파악
- "오류" 페이지는 즉시 수정

### 3. 모바일 사용성
- 모바일에서 문제가 있는 페이지 확인
- 터치 요소 간격, 글꼴 크기 등 점검

## 검색 노출까지 걸리는 시간

| 상황 | 예상 시간 |
|------|----------|
| 사이트맵 제출 후 첫 색인 | 1~7일 |
| 개별 URL 색인 요청 | 1~3일 |
| 검색 순위 안정화 | 1~3개월 |
| 상위 노출 | 3~6개월 (콘텐츠 품질에 따라) |

구글 서치 콘솔 등록은 블로그 운영의 기본 중 기본입니다. 10분이면 설정할 수 있으니, 아직 안 하셨다면 지금 바로 해보세요. 검색 유입이 시작되면 블로그 성장 속도가 완전히 달라집니다.
