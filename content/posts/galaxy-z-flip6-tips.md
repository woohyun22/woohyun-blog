## 갤럭시 Z 플립6, 제대로 쓰고 계신가요?

갤럭시 Z 플립6를 구매하셨지만 기본 기능만 사용하고 계시진 않나요? Z 플립6에는 일반 스마트폰에서는 경험할 수 없는 숨겨진 기능들이 가득합니다.

이 글에서 갤럭시 Z 플립6의 숨겨진 기능 10가지를 정리해 드립니다. 알고 나면 "이것도 되네?" 하실 겁니다.

## 1. 커버 화면 앱 확장하기

기본적으로 커버 화면에서 사용할 수 있는 앱은 제한되어 있습니다. 하지만 설정에서 모든 앱을 커버 화면에서 실행할 수 있습니다.

**설정 방법:**
1. 설정 → 커버 화면 → 커버 화면에서 앱 사용
2. 원하는 앱을 추가
3. 이제 폰을 접은 상태에서도 카카오톡, 유튜브 등 사용 가능

## 2. 플렉스 모드 카메라 활용

폰을 반으로 접어 세워놓으면 자동으로 플렉스 모드가 활성화됩니다.

- **셀카 삼각대**: 별도 삼각대 없이 타이머 셀카 촬영
- **핸즈프리 영상통화**: 책상에 세워놓고 편하게 통화
- **타임랩스**: 세워놓고 하늘, 음식 조리 과정 등 촬영

## 3. 빠른 카메라 실행

폰을 접은 상태에서 **측면 버튼 두 번 빠르게 누르면** 바로 카메라가 실행됩니다. 커버 화면이 뷰파인더가 되어 빠른 촬영이 가능합니다.

## 4. Galaxy AI 통역 기능

해외여행 시 Z 플립6를 반으로 접어 테이블에 놓으면, 위아래 화면이 각각 나와 상대방에게 보여집니다.

- 내가 말하면 → 번역된 텍스트가 상대방 화면에 표시
- 상대방이 말하면 → 번역된 텍스트가 내 화면에 표시

영어, 일본어, 중국어 등 16개 언어를 지원합니다.

## 5. 커버 화면 위젯 커스텀

커버 화면을 좌우로 넘기면 다양한 위젯을 사용할 수 있습니다.

**추천 위젯 구성:**
- 1페이지: 시계 + 날씨
- 2페이지: 일정 + 할 일
- 3페이지: 음악 컨트롤러
- 4페이지: 걸음 수 + 건강 정보

## 6. 제스처로 빠른 실행

플립을 열고 닫는 동작 자체를 제스처로 활용할 수 있습니다.

- **닫으면 전화 끊기**: 통화 중 폰을 접으면 자동 종료
- **열면 전화 받기**: 전화가 오면 폰을 펼치기만 하면 통화 시작

설정 → 유용한 기능 → 모션 및 제스처에서 활성화하세요.

## 7. 멀티 윈도우 활용

Z 플립6의 세로로 긴 화면을 활용해 위아래로 앱을 분할할 수 있습니다.

**활용 예시:**
- 위: 유튜브 시청 / 아래: 카카오톡 채팅
- 위: 레시피 보기 / 아래: 타이머 실행
- 위: 지도 앱 / 아래: 메모 앱

## 8. 커버 화면 삼성페이

폰을 접은 상태에서도 삼성페이를 사용할 수 있습니다. 커버 화면에서 위로 스와이프하면 결제 화면이 나타납니다. 주머니에서 꺼내 접힌 채로 바로 결제 가능합니다.

## 9. 배터리 절약 설정

Z 플립6의 배터리를 오래 쓰려면 이 설정을 꼭 해두세요.

- **커버 화면 AOD 끄기**: 설정 → 커버 화면 → Always On Display 비활성화
- **적응형 밝기 사용**: 자동으로 밝기 조절
- **5G 자동 전환**: 설정 → 연결 → 모바일 네트워크 → 5G 자동 전환

## 10. 사진 자동 보정 (Galaxy AI)

갤러리에서 사진을 열고 **AI 편집** 버튼을 누르면:
- 기울어진 사진 자동 보정
- 불필요한 객체 제거
- 흐린 사진 선명하게 복원

별도 앱 설치 없이 기본 갤러리에서 바로 사용 가능합니다.

갤럭시 Z 플립6는 접히는 폼팩터를 최대한 활용할 때 진가를 발휘합니다. 위 10가지 기능을 하나씩 설정해 보시면, 일반 스마트폰으로는 돌아가기 어려울 겁니다.
