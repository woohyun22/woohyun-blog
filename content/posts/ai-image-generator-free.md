## AI로 이미지를 무료로 만들 수 있다고?

프로필 사진, SNS 콘텐츠, 블로그 썸네일 등 이미지가 필요한 순간은 많은데, 디자인 실력이 없어도 AI가 해결해줍니다. 무료로 사용할 수 있는 AI 이미지 생성 사이트를 정리했습니다.

## 1. Microsoft Designer (구 Bing Image Creator)

**가격:** 완전 무료 (마이크로소프트 계정 필요)

**장점:**
- DALL-E 3 기반의 높은 품질
- 한국어 프롬프트 지원
- 매일 무료 크레딧 제공

**단점:**
- 생성 속도가 느릴 수 있음
- 상업적 사용 제한

**추천 용도:** 블로그 썸네일, SNS 이미지

## 2. Leonardo.ai

**가격:** 무료 (일 150토큰) / 유료 플랜 있음

**장점:**
- 다양한 AI 모델 선택 가능
- 고품질 이미지 생성
- 이미지 편집 기능 포함

**단점:**
- 무료 토큰 제한
- 영어 프롬프트가 더 정확

**추천 용도:** 전문적인 디자인, 게임 아트

## 3. Playground AI

**가격:** 무료 (일 100장) / 유료 플랜 있음

**장점:**
- 넉넉한 무료 할당량
- 직관적인 인터페이스
- 다양한 스타일 프리셋

**단점:**
- 고해상도는 유료
- 복잡한 프롬프트 처리 한계

**추천 용도:** 대량의 이미지가 필요할 때

## 4. Ideogram

**가격:** 무료 (일 제한 있음)

**장점:**
- 텍스트가 포함된 이미지 생성에 강함
- 로고, 포스터 제작에 적합
- 높은 이미지 품질

**단점:**
- 무료 생성 횟수 제한
- 생성 속도 느림

**추천 용도:** 로고, 텍스트가 포함된 디자인

## 5. Stable Diffusion (로컬 설치)

**가격:** 완전 무료 (오픈소스)

**장점:**
- 무제한 생성
- 완전한 커스터마이징
- 개인 정보 보호

**단점:**
- 설치가 복잡함
- 좋은 GPU 필요 (최소 8GB VRAM)

**추천 용도:** 대량 이미지 생성, 전문적인 활용

## AI 이미지 생성 팁

### 좋은 프롬프트 작성법
1. **구체적으로 설명하세요**: "고양이" → "햇살이 드는 창가에 앉아있는 주황색 고양이, 사진 스타일"
2. **스타일을 지정하세요**: "사진 스타일", "일러스트", "수채화", "3D 렌더링" 등
3. **부정 프롬프트를 활용하세요**: 원하지 않는 요소를 명시

### 주의사항
- 생성된 이미지의 저작권 정책을 확인하세요
- 실존 인물의 이미지를 생성하지 마세요
- 상업적 사용 시 각 서비스의 이용약관을 확인하세요
