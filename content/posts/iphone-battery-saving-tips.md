## 아이폰 배터리, 왜 이렇게 빨리 닳을까?

아이폰을 사용하다 보면 오후만 되면 배터리가 20% 이하로 떨어지는 경험을 하실 겁니다. 대부분 **설정 문제**입니다. 아래 설정을 변경하면 확실히 달라집니다.

## 1. 배경 앱 새로고침 끄기

사용하지 않는 앱이 백그라운드에서 계속 데이터를 갱신합니다.

**설정 방법:**
설정 → 일반 → 백그라운드 앱 새로고침 → 꼭 필요한 앱만 켜두기

**끄면 좋은 앱:**
- SNS 앱 (인스타그램, 페이스북)
- 쇼핑 앱
- 뉴스 앱
- 게임

## 2. 위치 서비스 최적화

GPS가 항상 켜져 있으면 배터리를 많이 소모합니다.

**설정 방법:**
설정 → 개인정보 보호 및 보안 → 위치 서비스

각 앱별로:
- "항상" → "앱을 사용하는 동안"으로 변경
- 불필요한 앱은 "안 함"으로 설정

## 3. 디스플레이 설정 조정

화면이 배터리를 가장 많이 소모합니다.

**설정 방법:**
- 설정 → 디스플레이 및 밝기 → 자동 밝기 켜기
- 자동 잠금을 "30초" 또는 "1분"으로 설정
- 다크 모드 사용 (OLED 화면에서 효과적)

## 4. 불필요한 알림 끄기

알림이 올 때마다 화면이 켜지고 배터리가 소모됩니다.

**설정 방법:**
설정 → 알림 → 각 앱별로 불필요한 알림 끄기

**특히 끄면 좋은 알림:**
- 게임 알림
- 쇼핑 앱 마케팅 알림
- 소셜 미디어 "좋아요" 알림

## 5. 메일 가져오기 설정 변경

메일을 "푸시"로 설정하면 실시간으로 확인하느라 배터리가 소모됩니다.

**설정 방법:**
설정 → 메일 → 계정 → 새로운 데이터 가져오기 → "수동"으로 변경

## 6. 배터리 상태 확인

배터리 성능 최대치가 80% 이하라면 교체를 고려하세요.

**확인 방법:**
설정 → 배터리 → 배터리 성능 상태

## 7. 저전력 모드 활용

배터리가 부족할 때 자동으로 켜지지만, 수동으로도 활성화 가능합니다.

**꿀팁:** 제어 센터에 저전력 모드 버튼을 추가하면 편리합니다.
설정 → 제어 센터 → 저전력 모드 추가

## 배터리 수명을 늘리는 충전 습관

1. **20~80% 사이에서 충전하세요** - 완전 방전/완충은 배터리 수명에 나쁩니다
2. **최적화된 배터리 충전을 켜세요** - 설정 → 배터리 → 배터리 성능 상태
3. **정품 충전기를 사용하세요** - 저가 충전기는 배터리 손상을 유발할 수 있습니다

## 마무리

이 설정들을 변경하면 배터리 사용 시간이 체감상 **1.5~2배** 정도 늘어납니다. 특히 **백그라운드 앱 새로고침 끄기**와 **위치 서비스 최적화**가 가장 효과적이니 이 두 가지부터 적용해보세요.
