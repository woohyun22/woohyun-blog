## 노션이 뭔가요?

**노션(Notion)**은 메모, 문서, 일정 관리, 데이터베이스를 하나로 합친 올인원 생산성 도구입니다. 무료로 사용할 수 있고, 개인 사용에는 충분한 기능을 제공합니다.

## 1단계: 가입 및 설치

### 웹 버전
1. [notion.so](https://notion.so) 접속
2. 구글 계정 또는 이메일로 가입
3. 바로 사용 시작

### 앱 설치
- **PC**: notion.so에서 다운로드
- **모바일**: 앱스토어/플레이스토어에서 "Notion" 검색

## 2단계: 기본 구조 이해하기

노션은 **페이지** 안에 **블록**을 쌓는 구조입니다.

### 블록 종류
- **텍스트**: 일반 텍스트 입력
- **제목**: H1, H2, H3 (글자 크기별 제목)
- **목록**: 불릿 목록, 번호 목록, 체크리스트
- **토글**: 접었다 펼 수 있는 내용
- **표**: 간단한 표 만들기
- **데이터베이스**: 정렬, 필터가 가능한 고급 표

### 블록 추가 방법
- 빈 줄에서 `/` 입력 → 블록 종류 선택
- 또는 왼쪽의 `+` 버튼 클릭

## 3단계: 자주 쓰는 단축키

| 단축키 | 기능 |
|--------|------|
| `/` | 블록 메뉴 열기 |
| `Ctrl + N` | 새 페이지 |
| `Ctrl + P` | 빠른 검색 |
| `Ctrl + B` | 굵게 |
| `Ctrl + Shift + H` | 형광펜 |
| `---` | 구분선 |
| `>` + 스페이스 | 토글 만들기 |
| `[]` + 스페이스 | 체크박스 |

## 4단계: 실용적인 활용법

### 1. 할 일 관리 (To-Do)
```
- [ ] 오늘 할 일 1
- [ ] 오늘 할 일 2
- [x] 완료된 일
```

### 2. 일기/메모장
- 매일 새 페이지를 만들 필요 없이 날짜별 토글로 관리
- 사진, 파일 첨부 가능

### 3. 독서 기록
데이터베이스로 만들면 편리합니다:
- 책 제목
- 저자
- 읽은 날짜
- 평점
- 메모

### 4. 가계부
간단한 표로 수입/지출을 관리할 수 있습니다.

### 5. 업무 프로젝트 관리
- 칸반 보드로 진행 상황 관리
- 팀원과 실시간 공유

## 5단계: 데이터베이스 기초

노션의 가장 강력한 기능입니다.

### 만드는 법
1. `/database` 입력
2. "데이터베이스 - 인라인" 선택
3. 속성(열) 추가: 텍스트, 날짜, 선택, 체크박스 등

### 보기 변경
같은 데이터를 다양한 형태로 볼 수 있습니다:
- **표 보기**: 엑셀처럼
- **보드 보기**: 칸반 보드처럼
- **캘린더 보기**: 달력처럼
- **갤러리 보기**: 카드형으로

## 꿀팁 모음

1. **템플릿 활용**: 노션 템플릿 갤러리에서 다양한 템플릿을 가져올 수 있습니다
2. **웹 클리퍼**: 크롬 확장 프로그램으로 웹페이지를 노션에 저장
3. **AI 기능**: 노션 AI로 글 요약, 번역, 아이디어 생성 가능
4. **하위 페이지**: 페이지 안에 페이지를 만들어 체계적으로 정리

## 무료 vs 유료

| 기능 | 무료 | 플러스 ($10/월) |
|------|------|----------------|
| 페이지 수 | 무제한 | 무제한 |
| 파일 업로드 | 5MB 제한 | 무제한 |
| 게스트 초대 | 10명 | 100명 |
| 버전 기록 | 7일 | 30일 |

**개인 사용이라면 무료 버전으로 충분합니다.**

## 마무리

노션은 처음에 어렵게 느껴질 수 있지만, 기본 개념(페이지 + 블록)만 이해하면 금방 익숙해집니다. **할 일 관리**부터 시작해서 점점 활용 범위를 넓혀보세요.
