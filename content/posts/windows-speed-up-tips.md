## 컴퓨터가 갑자기 느려졌다면?

윈도우11을 사용하다 보면 점점 느려지는 걸 느끼실 겁니다. 별도의 프로그램 설치 없이, 윈도우 설정만으로 속도를 개선하는 방법을 알려드리겠습니다.

## 1. 시작 프로그램 정리

컴퓨터 부팅 시 자동 실행되는 프로그램이 많으면 느려집니다.

**방법:**
1. `Ctrl + Shift + Esc`로 작업 관리자 열기
2. "시작 프로그램" 탭 클릭
3. 불필요한 프로그램을 선택하고 "사용 안 함" 클릭

**비활성화 추천 프로그램:**
- 각종 업데이트 프로그램
- 클라우드 동기화 (사용하지 않는 경우)
- 메신저 프로그램
- 게임 런처

## 2. 디스크 정리

임시 파일, 캐시 등이 쌓이면 디스크 공간을 차지하고 속도가 느려집니다.

**방법:**
1. `Win + I`로 설정 열기
2. 시스템 → 저장소
3. "임시 파일" 클릭
4. 삭제할 항목 선택 후 "파일 제거"

## 3. 시각 효과 끄기

예쁜 애니메이션이 시스템 자원을 잡아먹습니다.

**방법:**
1. `Win + R` → `sysdm.cpl` 입력 → 엔터
2. "고급" 탭 → 성능 "설정" 클릭
3. "최적 성능으로 조정" 선택
4. "화면 글꼴의 가장자리 다듬기"만 다시 체크
5. 적용

## 4. 전원 설정 변경

절전 모드는 성능을 제한합니다.

**방법:**
1. `Win + I`로 설정 열기
2. 시스템 → 전원
3. 전원 모드를 "최고 성능"으로 변경

## 5. 검색 인덱싱 제한

윈도우 검색이 백그라운드에서 파일을 계속 스캔합니다.

**방법:**
1. `Win + I` → 개인 정보 및 보안 → Windows 검색
2. "고급 인덱싱 옵션"에서 인덱싱 위치 줄이기
3. 필요한 폴더만 인덱싱하도록 설정

## 6. Windows 업데이트 확인

오래된 드라이버나 시스템 파일이 속도 저하를 유발할 수 있습니다.

**방법:**
1. `Win + I` → Windows 업데이트
2. "업데이트 확인" 클릭
3. 가용 업데이트 모두 설치
4. 재부팅

## 7. 불필요한 백그라운드 앱 끄기

사용하지 않는 앱이 백그라운드에서 실행되면 자원을 소모합니다.

**방법:**
1. `Win + I` → 앱 → 설치된 앱
2. 사용하지 않는 앱의 "..." 클릭
3. "고급 옵션" → 백그라운드 앱 사용 권한을 "안 함"으로 변경

## 추가 팁: SSD가 아직이라면?

위 방법을 모두 적용해도 느리다면, HDD를 SSD로 교체하는 것이 가장 확실한 방법입니다. 요즘 256GB SSD는 3만원대로 구매 가능합니다.

## 마무리

이 7가지 방법만 적용해도 체감 속도가 확실히 달라질 겁니다. 특히 **시작 프로그램 정리**와 **시각 효과 끄기**가 가장 효과적이니 이 두 가지부터 시도해보세요.
