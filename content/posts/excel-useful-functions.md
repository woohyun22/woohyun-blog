## 엑셀 함수, 이 10개만 알면 됩니다

엑셀 함수가 수백 개지만, 실무에서 정말 많이 쓰는 건 10개 정도입니다. 이 함수들만 익히면 업무 효율이 확 올라갑니다.

## 1. VLOOKUP - 데이터 찾기의 기본

다른 표에서 원하는 데이터를 찾아오는 함수입니다.

```
=VLOOKUP(찾을값, 범위, 열번호, FALSE)
```

**예시:** 사원번호로 이름 찾기
```
=VLOOKUP(A2, 사원목록!A:C, 2, FALSE)
```

**팁:** 마지막 인수는 반드시 `FALSE`(정확히 일치)를 사용하세요.

## 2. IF - 조건에 따라 다른 결과

조건이 참이면 A, 거짓이면 B를 출력합니다.

```
=IF(조건, 참일때, 거짓일때)
```

**예시:** 80점 이상이면 "합격"
```
=IF(B2>=80, "합격", "불합격")
```

## 3. SUMIF - 조건부 합계

특정 조건을 만족하는 값만 더합니다.

```
=SUMIF(조건범위, 조건, 합산범위)
```

**예시:** "영업팀"의 매출 합계
```
=SUMIF(A:A, "영업팀", C:C)
```

## 4. COUNTIF - 조건부 개수

특정 조건을 만족하는 셀의 개수를 셉니다.

```
=COUNTIF(범위, 조건)
```

**예시:** "합격"인 사람 수
```
=COUNTIF(D:D, "합격")
```

## 5. INDEX + MATCH - VLOOKUP의 상위 버전

VLOOKUP보다 유연하고 강력합니다.

```
=INDEX(결과범위, MATCH(찾을값, 검색범위, 0))
```

**예시:** 제품명으로 가격 찾기
```
=INDEX(C:C, MATCH(A2, B:B, 0))
```

**VLOOKUP과의 차이:** 왼쪽에 있는 열도 검색 가능합니다.

## 6. TEXT - 날짜/숫자 서식 변환

숫자나 날짜를 원하는 텍스트 형식으로 바꿉니다.

```
=TEXT(값, 서식)
```

**예시:**
```
=TEXT(TODAY(), "YYYY년 MM월 DD일")  → "2026년 07월 27일"
=TEXT(1234567, "#,##0")            → "1,234,567"
```

## 7. CONCATENATE (또는 &) - 텍스트 합치기

여러 셀의 텍스트를 하나로 합칩니다.

```
=A1 & " " & B1
```

**예시:** 성과 이름 합치기
```
=A2 & B2  → "김철수"
```

## 8. LEFT, RIGHT, MID - 텍스트 추출

텍스트의 일부분을 추출합니다.

```
=LEFT(텍스트, 글자수)   → 왼쪽에서 추출
=RIGHT(텍스트, 글자수)  → 오른쪽에서 추출
=MID(텍스트, 시작위치, 글자수) → 중간에서 추출
```

**예시:** 주민번호에서 생년 추출
```
=LEFT(A2, 6)  → "901225"
```

## 9. IFERROR - 에러 처리

함수 결과가 에러일 때 대체 값을 표시합니다.

```
=IFERROR(수식, 에러시_값)
```

**예시:** VLOOKUP 에러 방지
```
=IFERROR(VLOOKUP(A2, B:C, 2, FALSE), "해당없음")
```

## 10. PIVOT TABLE (피벗 테이블)

함수는 아니지만, 반드시 알아야 하는 기능입니다.

**만드는 법:**
1. 데이터 영역 선택
2. 삽입 → 피벗 테이블
3. 행/열/값에 필드 배치

**활용:**
- 부서별 매출 합계
- 월별 판매 현황
- 고객별 구매 빈도
