## 노트북이 뜨거워서 무릎 위에 올려놓기 힘드시죠?

여름이 되면 노트북 발열 문제로 고생하는 분들이 많습니다. 노트북이 뜨거워지면 성능 저하(쓰로틀링)가 발생하고, 심하면 부품 수명이 줄어듭니다.

이 글에서 노트북 발열을 즉시 줄일 수 있는 해결법 8가지를 소프트웨어와 하드웨어로 나누어 알려드립니다.

## 소프트웨어 해결법

### 1. 전원 옵션 변경

윈도우의 전원 옵션을 조정하면 발열을 크게 줄일 수 있습니다.

**설정 방법:**
1. 설정 → 시스템 → 전원 → 추가 전원 설정
2. 전원 관리 옵션에서 "균형 조정" 또는 "절전" 선택
3. 고급 전원 관리에서 "최대 프로세서 상태"를 90%로 제한

CPU 최대 성능을 10%만 제한해도 발열이 크게 줄고, 체감 성능 차이는 거의 없습니다.

### 2. 백그라운드 프로세스 정리

불필요한 프로그램이 백그라운드에서 CPU를 사용하고 있을 수 있습니다.

- **Ctrl + Shift + Esc** → 작업 관리자 실행
- CPU 사용률 높은 프로세스 확인
- 불필요한 시작 프로그램 비활성화

특히 클라우드 동기화 프로그램(OneDrive, Dropbox)이 백그라운드에서 발열을 일으키는 경우가 많습니다.

### 3. GPU 사용 관리

외장 GPU가 있는 노트북은 GPU가 발열의 주범인 경우가 많습니다.

- **NVIDIA 제어판** → 프로그램 설정에서 일반 작업은 내장 GPU 사용으로 변경
- 게임이나 영상 편집 시에만 외장 GPU 활성화
- GPU 드라이버를 최신 버전으로 업데이트

### 4. 크롬 탭 관리

크롬 브라우저는 탭을 많이 열수록 메모리와 CPU를 과도하게 사용합니다.

- 사용하지 않는 탭 닫기 (10개 이하 유지)
- 탭 관리 확장 프로그램 사용 (The Great Suspender 등)
- 하드웨어 가속 비활성화: 설정 → 시스템 → "가능한 경우 하드웨어 가속 사용" 끄기

## 하드웨어 해결법

### 5. 쿨링 패드 사용

가장 즉각적인 효과를 볼 수 있는 방법입니다.

**쿨링 패드 선택 팁:**
- 노트북 크기에 맞는 제품 선택 (15인치면 15인치용)
- 팬 소음 확인 (25dB 이하 추천)
- 높이 조절 가능한 제품이 인체공학적으로도 좋음
- 가격대: 2~3만 원이면 충분

쿨링 패드 하나로 노트북 온도를 5~10도 낮출 수 있습니다.

### 6. 통풍구 확인 및 청소

노트북 하단과 측면의 통풍구가 먼지로 막혀 있으면 열이 빠져나가지 못합니다.

**청소 방법:**
- 압축 공기 스프레이로 통풍구의 먼지 제거
- 부드러운 브러시로 외부 먼지 제거
- 6개월~1년에 한 번 전문 업체에서 내부 청소 권장

### 7. 노트북 받침대 활용

노트북을 평평한 책상에 직접 놓으면 바닥 통풍구가 막힙니다.

- 노트북 스탠드나 받침대를 사용해 바닥에서 띄우기
- 없다면 책 2권을 양쪽에 놓아 경사를 만들기
- 침대나 쿠션 위에서 사용하지 않기 (통풍구 완전 차단)

### 8. 서멀 구리스 재도포

노트북을 3년 이상 사용했다면 CPU와 방열판 사이의 서멀 구리스가 마른 상태일 수 있습니다.

- 직접 교체 가능하지만, 자신 없으면 전문 업체 의뢰 (2~3만 원)
- 교체 후 온도가 10~20도 하락하는 경우도 많음
- 추천 서멀 구리스: Thermalright TFX, Noctua NT-H1

## 발열 상태 확인하는 방법

**HWMonitor** 프로그램(무료)으로 현재 온도를 확인할 수 있습니다.

| CPU 온도 | 상태 |
|----------|------|
| ~60도 | 정상 (안심) |
| 60~80도 | 보통 (관리 필요) |
| 80~90도 | 주의 (위 방법 적용) |
| 90도 이상 | 위험 (즉시 조치) |
