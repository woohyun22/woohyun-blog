## 아직도 모든 사이트에 같은 비밀번호 쓰고 계신가요?

한국인터넷진흥원(KISA) 조사에 따르면, 응답자의 약 62%가 여러 사이트에서 동일한 비밀번호를 사용한다고 합니다. 하나의 사이트에서 개인정보가 유출되면 나머지 모든 계정이 위험해집니다.

이 글에서 안전한 비밀번호를 만들고 편리하게 관리하는 방법을 알려드립니다.

## 위험한 비밀번호 습관

### 절대 하면 안 되는 것들
- 모든 사이트에 같은 비밀번호 사용
- 생년월일, 전화번호, 이름 조합 (예: `kim1990!`)
- 연속 숫자/키보드 패턴 (예: `123456`, `qwerty`)
- 포스트잇에 비밀번호 메모
- 카카오톡이나 메모장에 비밀번호 저장

### 2026년 가장 많이 해킹당한 비밀번호
1. `123456`
2. `password`
3. `123456789`
4. `qwerty123`
5. `abc123`

이런 비밀번호는 해커가 **1초 이내에** 뚫을 수 있습니다.

## 안전한 비밀번호 만드는 법

### 규칙 1: 길이가 가장 중요

| 비밀번호 길이 | 해킹 소요 시간 |
|-------------|-------------|
| 6자리 | 즉시 |
| 8자리 (영+숫자) | 약 1시간 |
| 12자리 (영+숫자+특수) | 약 3만 4천 년 |
| 16자리 (영+숫자+특수) | 사실상 불가능 |

**최소 12자리 이상**을 사용하세요.

### 규칙 2: 문장형 비밀번호 만들기

외우기 쉬우면서 안전한 비밀번호를 만드는 방법입니다.

**방법**: 기억하기 쉬운 문장을 만들고, 규칙을 적용합니다.

예시:
- 문장: "나는 매일 아침 7시에 커피를 마신다"
- 변환: `Na-Mae7si-Coffee!`
- 사이트별 변형: `Na-Mae7si-Coffee!Goo` (구글), `Na-Mae7si-Coffee!Nav` (네이버)

### 규칙 3: 사이트마다 다른 비밀번호

같은 기본 구조에 사이트별 접미사를 붙이면 됩니다.

- 구글: `MyP@ss2026-GG`
- 네이버: `MyP@ss2026-NV`
- 인스타: `MyP@ss2026-IG`

## 비밀번호 관리자 앱 추천

사이트마다 다른 비밀번호를 외우는 것은 불가능합니다. 비밀번호 관리자를 사용하세요.

### 1. 1Password
- 가장 안전하고 기능이 풍부
- 가족 요금제 지원
- 월 $2.99

### 2. Bitwarden (추천)
- **무료**로 충분히 사용 가능
- 오픈소스라 투명한 보안
- 모든 기기 동기화 무료

### 3. 삼성 패스 / iCloud 키체인
- 삼성/애플 기기 사용자라면 기본 내장
- 별도 앱 설치 불필요
- 무료

### 비밀번호 관리자 사용법
1. 마스터 비밀번호 하나만 기억 (최대한 길고 안전하게)
2. 나머지 모든 사이트의 비밀번호는 자동 생성
3. 로그인할 때 자동 입력

**마스터 비밀번호만 잘 기억하면** 나머지는 앱이 다 해줍니다.

## 2단계 인증 (2FA) 설정하기

비밀번호만으로는 부족합니다. 2단계 인증을 꼭 설정하세요.

### 2단계 인증이란?
비밀번호 입력 후 추가로 본인 확인을 하는 것입니다.
- 문자 인증 코드
- 인증 앱 코드 (Google Authenticator, Microsoft Authenticator)
- 생체 인증 (지문, 얼굴)

### 반드시 2FA를 설정해야 하는 서비스
1. **이메일** (Gmail, 네이버 메일) — 모든 계정의 복구 수단
2. **금융 서비스** (은행, 증권)
3. **SNS** (인스타그램, 페이스북)
4. **클라우드** (구글 드라이브, iCloud)

### 설정 방법 (구글 계정 예시)
1. 구글 계정 → 보안 → 2단계 인증
2. 전화번호 또는 인증 앱 등록
3. 백업 코드 저장 (안전한 곳에 보관)

## 해킹 의심 시 대처법

1. **즉시 비밀번호 변경**: 해당 사이트 + 같은 비밀번호 사용 사이트 모두
2. **2단계 인증 확인**: 내가 모르는 기기가 연결되어 있지 않은지
3. **로그인 기록 확인**: 구글, 네이버 등에서 최근 로그인 위치 확인
4. **신용카드 확인**: 금융 관련 계정이라면 결제 내역 확인
5. **KISA 신고**: 118 전화 또는 인터넷 침해 대응센터 신고

## 마무리

비밀번호 관리는 귀찮지만, 해킹당한 후 복구하는 것은 100배 더 귀찮습니다. 오늘 딱 2가지만 하세요.

1. **비밀번호 관리자 앱 설치** (Bitwarden 추천, 무료)
2. **이메일에 2단계 인증 설정**

이 두 가지만 해도 보안 수준이 크게 올라갑니다.
